# Course cover assets

`app/course/covers.py` всегда генерирует отдельную квадратную JPEG-обложку для каждой части урока локально и детерминированно. JPEG выбран для совместимости с текущими Telegram/MAX/Dzen adapters.

Renderer `thematic-v2` всегда строит содержательную иллюстрацию из темы и учебной цели урока. Он выбирает визуальный сюжет — текст и языковые модели, prompting, проверка надёжности, данные, автоматизация, мультимедиа, рабочие сценарии или творчество — и рисует соответствующую композицию в общей фирменной системе. Поэтому отсутствие ручного файла больше не включает старую абстрактную карточку.

Для конкретного урока при необходимости art-direction можно сохранить одну постоянную иллюстрацию:

```text
assets/course/lesson_art/season_NN_lesson_NN.jpg
```

Один необязательный исходник повторно используется для всех трёх частей урока. Renderer сам добавляет русские надписи, номер части и разные цветовые акценты; внешняя генерация во время подготовки и публикации не вызывается. Сейчас такой override добавлен для `season_01_lesson_02.jpg`.

Тематическая композиция создаётся для каждого lesson независимо. Общая палитра по-прежнему согласована с пятью сезонами курса.

- Season 1 — светящиеся орбиты и точки основ;
- Season 2 — prompt-сигналы и диалоговая геометрия;
- Season 3 — data-grid и поисковая линза;
- Season 4 — связанные workflow-блоки;
- Season 5 — agent/circuit network.

Общий branding, левая информационная панель и типографика едины. Для special day вместо `УРОК N ИЗ 15` выводится `cover_label`. Внешние image API не вызываются.

Уже prepared lesson можно обновить через `app.course.service.rebuild_prepared_lesson_covers(day)`. Для частично начатого дня разрешён rebuild только ещё не публиковавшихся частей, например `rebuild_prepared_lesson_covers(day, (PartType.REINFORCE,))`. Операция заменяет только `image_reference`, `image_hash` и `image_data`, не вызывает AI и не меняет текст; каждая часть с существующей platform publication блокируется.

Полный тест рендерит все 420 JPEG при `quality=90`, проверяет размер `1080×1080`, детерминированный hash, различие сезонных/тематических композиций и общий лимит хранения менее 100 MiB.
